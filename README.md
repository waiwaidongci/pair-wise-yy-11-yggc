# hxyfront-62010 潜水气瓶充填记录

源提示词编号：5

给潜水店使用的气瓶充填前端系统，覆盖「充填登记 → 静置稳压 → 复检 → 签收 / 返工」完整闭环。

## 功能闭环

- **充填登记**：每次充填记录残压、充填后压力、目标压力、目标氧氦比例、完成时间、气源批次、操作员；支持空气 / 高氧 / Trimix 常用配比预设与混合气比例提示。
- **待复测唯一性**：同一气瓶同一时刻只能有一条待复测记录；重复提交沿用首次记录，不新建、不覆盖，并高亮定位原记录。
- **稳压复检签收规则**（不达标不得签收，只能转返工并写明超限项）：
  - 静置时长 ≥ 30 分钟
  - 压力下降 ≤ 5 bar
  - 氧、氦含量偏差 ≤ ±1 个百分点
  - 气源批次须处于在用状态
- **返工**：复检不通过时按钮自动切换为「转返工」，必须逐项列出超限内容并填写返工说明；返工后气瓶重新进入待充填队列。
- **气源冻结与恢复**：气源批次停用会冻结其名下所有未签收复测，记录在列表中标记「冻结」；补录合格气源并对冻结记录重新检测合格后才恢复签收（复检记录追加补录气源）。
- **已签收只可追加**：签收记录锁定，原始充填数据不可改写，复检结果以追加字段保存。
- **一致性**：全部数据保存在浏览器 localStorage，刷新后列表、统计与单瓶历史保持一致；支持按状态 / 充填方式筛选、关键字搜索与 CSV 导出。
- 气瓶检验过期 / 临期（30 天内）自动提醒，过期气瓶禁止新充填。

## 技术栈

React 19 + Vite 7 + TypeScript（数据仅前端本地存储，无后端）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：62010

## 规则单元测试

复检判定规则集中在 `src/lib/validation.ts`，测试覆盖静置时长、压降、氧氦偏差边界、气源冻结与多项超限：

```bash
npx esbuild scripts/validation.test.mjs --bundle --platform=node --format=esm \
  --outfile=node_modules/.tmp/validation.test.mjs \
  && node node_modules/.tmp/validation.test.mjs
```
